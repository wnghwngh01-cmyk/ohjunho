방금 만든 "하루를 담다 - 가계부" 화면을 아래 항목만 고쳐 주세요.
나머지 디자인·배치·색·문구는 지금 그대로 두고, 여기 적힌 것 외에는 아무것도 바꾸거나 추가하지 마세요.
출력 형식도 지난번과 같습니다: 정적 HTML(code.html) + screen.png, JavaScript로 화면을 그리지 않기, style 속성 없이 Tailwind 클래스만.

1. 없는 분류 사용 금지
   - 일시정지된 정기 거래 예시의 분류 "운동"은 앱에 없는 분류입니다. "생활"로 바꿔 주세요.
   - 분류는 지출: 식비·교통·쇼핑·생활·교육·세금·기타 / 수입: 급여·용돈·기타, 이 목록만 씁니다.

2. 분류 선택 칸의 항목을 전부 넣기
   - "거래 수정" 편집 칸의 분류 선택과 "새 정기 거래 등록" 칸의 분류 선택에 지출 분류 7개(식비·교통·쇼핑·생활·교육·세금·기타)를 모두 넣어 주세요. 지금은 일부가 빠져 있습니다.

3. 기록 검색 칸
   - 날짜 입력의 기본값(2026-11-01)을 지우고 빈칸으로 두세요. 값이 있으면 그 날짜로 목록이 걸러집니다.
   - 이름 검색 placeholder를 "기록 이름 검색"으로 바꿔 주세요.

4. 거래 줄 앞의 동그란 색 점을 빼 주세요. 수입·지출 구분 없이 같은 색이라 의미가 없습니다. 점을 뺀 만큼 내용 글자가 왼쪽으로 붙으면 됩니다.

5. 문구를 처음 요청대로
   - 수입·지출 분석의 전환 버튼: "지출 분석"/"수입 분석" → "지출"/"수입"
   - 정기 수입·지출의 "+ 정기 거래 추가" → "추가"
   - 새 정기 거래 등록의 "종료일 (선택)" → "종료일 (비워두면 계속)"
   - 날짜 묶음 머리 "11월 01일 일요일" → "11월 1일 일요일" (날짜 앞에 0을 붙이지 않음)

6. 머리글 알림 점을 더보기 화면과 같은 크기로: 점을 w-2 h-2 (지금은 w-1.5 h-1.5)로 바꿔 주세요. 위치(top-2.5 right-2.5)와 색은 그대로.

7. 예시 숫자 맞추기: 월별 예산의 식비 줄은 "300,000원 중 180,000원 사용 · 120,000원 남음"인데, 아래 "예산 설정·수정" 칸의 식비 안내는 "사용 120,000원 · 180,000원 남음"으로 거꾸로 되어 있습니다. "현재 예산 300,000원 · 사용 180,000원 · 120,000원 남음"으로 맞춰 주세요.

## 검토하면서 고치지 않기로 한 것 (앱에 옮길 때 처리)
- code.html의 월별 예산·정기·분석 칸이 `open`(펼친 상태)으로 되어 있음 → 옮길 때 닫힌 상태로 바꿈
- 일부 버튼 높이가 32~40px로 44px보다 작음 → 오늘·캘린더와 같이 보이지 않는 44px 터치 영역을 CSS로 덧붙임
- 요약 카드 막대 길이·도넛 비율·각종 금액 → 실제 데이터로 계산해 넣음
- 기준 시간대 칸이 읽기 전용으로 그려짐 → 지금 앱처럼 기기 시간대를 기본값으로 넣고 그대로 둠
