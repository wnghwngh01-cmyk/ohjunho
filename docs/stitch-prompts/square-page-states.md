# Stitch 프롬프트: 광장 상태 모음 화면 (2026-11-20)

목적: 확정된 "광장 (발견)", "광장 (앱 개선)" 2장은 건드리지 않고, 그림이 없던 상태들을 새 화면 1장에 모아 받는다.

---

이미 확정한 "광장 (발견)", "광장 (앱 개선)" 화면 2장은 **절대 수정하지 말고**, 새 화면 1장 "광장 - 상태 모음"을 만들어 주세요.
이 화면은 앱에서 데이터에 따라 나타나는 여러 상태를 한곳에 모아 보여 주는 참고 화면입니다. 새 디자인을 만들지 말고, **"광장 (발견)" 화면에 이미 있는 카드·배지·버튼·입력칸의 클래스를 그대로 복사해서** 아래 상태만 그려 주세요.
규칙은 지난번과 같습니다: 정적 code.html + screen.png, JavaScript로 그리지 않기, style 속성 없이 Tailwind 클래스만, 페이지 제목·알림 종 없음, 하단 탭바 없음, 대장간 증명서·검 그림은 그리지 않고 빈 자리 상자만, 문구는 아래 그대로.

각 상태 위에 작은 회색 구분 제목(text-[11px] font-semibold text-[#8E928F])을 달아 주세요(예: "① 사진 1장"). 이 구분 제목은 참고용입니다.

① 사진 1장인 "일기" 글 카드
- 사진 격자 대신 사진 1장을 가로 전체 폭, 4:3 비율(aspect-[4/3]), 모서리 rounded-xl, 회색 상자.
- 종류 배지 "일기": bg-[#EBF7F0] text-[#1E3A2F] (모양은 다른 종류 배지와 같게).
- 남의 글, 팔로우 안 한 상태, 칭호 배지 없음. 나머지(제목, 본문, 시각, 동작 줄)는 발견 화면 카드와 같게.

② 사진 2장인 "기록" 글 카드
- 사진 2장을 2칸(grid grid-cols-2 gap-1.5), 각 칸 정사각형(aspect-square), 회색 상자.
- 나머지는 발견 화면 (가) 카드와 같게.

③ 부고 대장간 글 카드
- 발견 화면 대장간 카드와 같고, 좋아요 버튼 글자만 "🌼 헌화하기"(숫자는 따로 <span>, 예: 12).
- 증명서 자리는 빈 상자 + "대장간 증명서 자리" 글자.

④ 댓글이 하나도 없는 글의 댓글 영역(펼친 상태)
- 발견 화면 (나) 카드의 댓글 영역 모양 그대로, 댓글 목록 자리에 가운데 정렬 작은 회색 글자 "첫 댓글을 남겨보세요."(text-xs text-[#8E928F]) + 아래 댓글 입력 줄(placeholder "댓글을 입력하세요", "등록" 버튼).
- 카드 전체를 다시 그리지 말고 댓글 영역 상자만 그려도 됩니다.

⑤ 발견 탭 목록이 비었을 때
- 흰 카드(다른 카드와 같은 모양) 안에 가운데 정렬로 작은 회색 글자 "아직 광장에 공유된 내용이 없습니다."(text-xs text-[#8E928F], 위아래 여백 넉넉히 py-10).

⑥ 팔로잉 탭 목록이 비었을 때
- ⑤와 같은 모양, 문구 "팔로우한 연구실의 새 공유가 아직 없습니다."

⑦ 앱 개선 제안이 하나도 없을 때
- ⑤와 같은 모양, 문구 "첫 개선 제안을 남겨보세요."

⑧ 광장 준비 중(광장 기능이 꺼져 있을 때)
- ⑤와 같은 모양, 굵은 글자 "광장을 준비하고 있습니다."(text-sm font-semibold text-[#424844]).
