# Stitch 수정 프롬프트: 운동 1차 (2026-11-21)

1차 결과(_26 운동 관리, _25 단백질 기록) 검토: 요청한 항목·문구는 모두 있고 style 속성·JS 렌더링 없음.
고칠 점: "운동 삭제"가 "이전 기록" summary 안에 들어가 누르면 기록이 같이 접히고 펼쳐짐, 메모 칸에 이름표가 없음,
긴 운동·음식 이름이 360px에서 넘칠 수 있음, 바깥 여백·라벨 색이 다른 화면과 다름, 빈 상태 화면 없음.

---

운동 화면 2장을 아래처럼 고치고, 상태 모음 화면 1장을 새로 만들어 주세요. 다른 화면(오늘·캘린더·더보기·가계부·광장)은 절대 건드리지 마세요. 출력 형식은 지난번과 같습니다.
[운동 - 운동 관리 고칠 점]
1. "운동 삭제" 버튼을 "이전 기록" summary 밖으로 빼 주세요. summary 안에는 "이전 기록" 글자와 화살표만 둡니다. "운동 삭제"는 펼친 운동의 맨 아래 줄 오른쪽에 따로 둡니다(부위 카드의 "부위 삭제"와 같은 모양: class="min-h-[44px] px-2 text-xs font-medium text-[#B45650] whitespace-nowrap").
2. 메모 입력칸 위에도 "운동 이름"과 같은 모양의 이름표 "메모 (선택)"를 붙이고, placeholder는 "예: 다음에는 마지막 세트 10회"로 해 주세요.
3. 이름표(운동 이름, 메모)는 class="block text-[11px] font-semibold text-[#424844] mb-1"로 해 주세요(광장 앱 개선의 이름표와 같게).
4. 접힌 운동 줄: 운동 이름을 윗줄, 요약("3세트 · 60kg × 10회")을 아랫줄에 두 줄로 쌓아 주세요. 이름은 길면 말줄임(truncate), 감싸는 div에 min-w-0 flex-1. 부위 머리 줄도 이름 부분에 min-w-0 + truncate.
5. 바깥 컨테이너를 다른 화면과 같게: class="max-w-[480px] mx-auto px-4 pt-4 pb-[96px] space-y-3".
[운동 - 단백질 기록 고칠 점]
6. 기록 줄의 음식 이름 부분: 감싸는 div에 min-w-0 flex-1, 이름 span에 truncate. 오른쪽(그램 + 삭제)은 shrink-0.
7. 단백질 입력칸에 aria-label="단백질(g)"을 붙여 주세요. 모양은 지금 그대로.
8. 바깥 컨테이너도 5번과 같게.
[새 화면: 운동 - 상태 모음]
같은 디자인으로 아래 상태 5개를 한 화면에 위에서부터 차례로 그려 주세요. 각 상태 위에 작은 회색 제목(예 "① 부위가 없을 때")을 붙여 구분해 주세요. 탭은 맨 위에 한 번만.
① 부위가 없을 때: 흰 카드 안 가운데 "아직 만든 부위가 없습니다." + 작은 글씨 "가슴, 등, 하체처럼 원하는 이름으로 추가해 보세요." 그 아래 부위 추가 카드.
② 부위를 펼쳤는데 운동이 없을 때: 부위 "어깨"(운동 0개) 펼침, 안에 작은 회색 글씨 "아직 운동이 없습니다. 아래에서 추가해 보세요." + 운동 추가 줄 + 부위 삭제.
③ 처음 만든 운동을 펼쳤을 때: 운동 "사이드 레터럴 레이즈", 세트 1개(0 × 0), 메모 비어 있음, 이전 기록 펼침 상태에서 "저장된 이전 기록이 없습니다."
④ 단백질 - 다른 날짜에 기록이 없을 때: 날짜 "11월 20일 (금)", 합계 카드 "11월 20일 섭취량" "0 g", 추가 줄, 목록 카드 안 가운데 "이 날짜에는 아직 기록이 없습니다."
⑤ 단백질 - 음식 이름 없이 넣은 기록: 목록에 "단백질 30 g"(이름 없으면 "단백질"로 표시) 1줄과 아주 긴 이름 "편의점 닭가슴살 스테이크 오리지널 맛 2팩" 25 g 1줄(말줄임 확인용).
