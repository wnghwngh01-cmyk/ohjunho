# Stitch 수정 프롬프트 2차: 가계부 화면 (2026-11-20)

대상: "하루를 담다 - 가계부 (Account 메인 수정본)" (export 폴더 stitch_ui/account_2)
1차 수정 결과 검증: 12개 항목 중 10개 반영. 남은 2개 + 1차 수정 중 새로 생긴 잘못 1개.

---

방금 만든 "가계부 (Account 메인 수정본)" 화면에서 "새 정기 거래 등록" 입력 칸만 아래 3가지를 고쳐 주세요. 다른 부분은 한 글자도 바꾸지 마세요. 출력 형식은 지난번과 같습니다.

1. 라벨이 잘못 바뀌었습니다. 숫자 입력칸(min 1, max 31, 값 25)의 라벨이 지금 "종료일 (비워두면 계속)"으로 되어 있습니다. 원래대로 "매월 기록일 (1~31)"로 되돌려 주세요.
2. 그 아래 날짜 입력칸(placeholder "비워두면 계속")의 라벨 "종료일 (선택)"을 "종료일 (비워두면 계속)"으로 바꿔 주세요.
3. 같은 칸의 분류 선택에 쇼핑과 세금이 빠져 있습니다. 옵션을 정확히 이 순서로: 식비, 교통, 쇼핑, 생활(선택됨), 교육, 세금, 기타.

---

결과("최종 수정본", account_3): 1번만 반영. Stitch는 3개 모두 했다고 답했지만 코드에는 2·3번이 그대로였다.

## 3차 (같은 화면을 선택한 채 정확한 HTML을 지정)

"새 정기 거래 등록" 칸의 분류 select 옵션을 정확히
`<option>식비</option><option>교통</option><option>쇼핑</option><option selected>생활</option><option>교육</option><option>세금</option><option>기타</option>`
로, 날짜 입력(placeholder "비워두면 계속") 위 라벨 "종료일 (선택)"을 "종료일 (비워두면 계속)"으로. "매월 기록일 (1~31)"은 그대로.

결과(같은 화면 갱신): 1·2차 요청 12개 항목 모두 코드에서 확인. 첫 버전과 비교한 글자·클래스 차이는 요청한 것뿐.
최종 파일: Downloads\하루를담다_디자인_최종_20261120\가계부\ (code.html, screen.png)
사용자 결정(같은 날): 페이지 위의 제목("가계부")과 알림함은 넣지 않는다. 알림함은 오늘 페이지에만 있다.
→ 앱에 적용할 때 이 디자인의 1번 머리글(제목 + 종 버튼) 블록을 빼고 2번 월 이동 줄부터 쓴다. 더보기 화면의 머리글도 같은 이유로 제거함.
참고: 이 screen.png는 버튼 글자가 한 글자씩 줄바꿈된 것처럼 보이지만, code.html을 360px에서 직접 렌더해 보면 줄바꿈 0건(이미지 렌더링 차이).
