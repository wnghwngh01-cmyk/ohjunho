# Stitch 프롬프트: 가계부 화면 (2026-11-20)

아래 구분선 사이 전체를 Stitch에 그대로 붙여 넣는다.

---

[목적]
이 프로젝트에서 이미 완성한 "오늘", "캘린더", "더보기" 화면과 같은 앱 "하루를 담다"의 **가계부 화면 1장**을 만들어 주세요.
새 앱을 디자인하는 것이 아닙니다. 이미 작동하는 기능의 **화면 디자인만** 바꾸는 작업입니다.
그러니 아래에 적힌 기능과 항목만 정확히 그려 주세요. 적혀 있지 않은 기능, 버튼, 그래프, 메뉴는 절대 추가하지 마세요.

[앱과 화면 위치]
- 앱: "하루를 담다" (안드로이드 앱, 휴대폰 세로 화면 전용, 한국어)
- 이 화면으로 오는 길: 하단 탭바의 세 번째 탭 "가계부", 또는 더보기 → 생활 → "가계부"
- 하단 탭바(오늘 · 캘린더 · 가계부 · 광장 · 더보기)는 앱에 이미 있으므로 **그리지 마세요.** 화면 아래쪽에 탭바가 덮을 96px 여백만 남겨 주세요.
- 이 화면의 역할: 수입과 지출을 기록하고, 이번 달 예산이 얼마나 남았는지 보고, 지난 기록을 찾는 개인 가계부입니다. 은행·카드 연동은 없습니다. 사용자가 직접 적습니다.

[디자인 기준: 이미 만든 3개 화면과 똑같이]
- 오늘·캘린더·더보기 화면의 디자인 시스템을 그대로 씁니다. 새로운 색, 새로운 카드 모양, 새로운 글꼴을 만들지 마세요.
- 바탕 #FAF9F6, 카드 흰색 #FFFFFF + 테두리 1px #F0EFEA(또는 #E9E8E5), 카드 모서리 rounded-2xl(16px), 그림자는 아주 옅게(0 2px 8px rgba(0,0,0,0.025))
- 주색 숲녹색 #1E3A2F(버튼, 강조 숫자, 선택된 상태), 진한 숲녹색 #162C23(눌림), 연한 녹색 배경 #E8F1EC, 민트 배지 #C3ECD6 / 글자 #133E2B
- 글자: 기본 #1A1C1A, 보조 #424844, 흐린 글자 #8E928F
- 지출·초과·삭제 같은 경고 계열: 코랄 #B45650 (연한 배경 #FDF0EE, 연한 테두리 #FAD4D1)
- 수입 금액: 숲녹색 #1E3A2F
- 그 밖의 분류 색이 필요하면 캘린더에서 쓴 색만 사용: 민트 #EBF7F0/#1E3A2F, 스틸블루 #EDF3F8/#4E70A0, 앰버 #FEF6EC/#C97A1E, 코랄 #FDF0EE/#B45650
- 글꼴: Pretendard(없으면 Noto Sans KR), 제목은 굵게 하되 너무 두껍지 않게
- 아이콘: 다른 화면과 같은 선 아이콘(lucide 스타일, stroke 1.5, 둥근 끝), 인라인 SVG
- 폭: 390px 기준, 콘텐츠 최대 폭 480px, 좌우 여백 16px. 360px에서도 글자나 버튼이 잘리지 않게.
- 버튼과 체크 같은 누르는 것은 최소 44px 높이의 터치 영역

[화면 구성: 위에서부터 이 순서대로, 이 내용만]

1. 머리글 (더보기 화면 머리글과 같은 모양)
   - 왼쪽: 제목 "가계부"
   - 오른쪽: 알림 종 아이콘 버튼(안 읽은 알림이 있을 때만 작은 코랄 점)

2. 월 이동 줄
   - 가운데 또는 왼쪽: "2026년 11월"
   - 이전 달 ‹ 버튼, 다음 달 › 버튼, "이번 달" 버튼 (캘린더 화면 월 이동과 같은 모양)
   - 아래 모든 숫자와 목록은 여기서 고른 달 기준입니다.

3. 요약 카드 (한 장)
   - 큰 글씨: "이번 달 남은 예산" 라벨 + 금액 "420,000원" + 작게 "/ 총 800,000원"
     - 다른 달을 보고 있으면 라벨이 "2026년 10월 남은 예산"으로 바뀝니다.
     - 예산을 넘으면 금액이 코랄색 "35,000원 초과"로 바뀝니다.
     - 예산이 하나도 없으면 금액 자리에 "예산 설정하기" 글자 버튼이 나옵니다(누르면 아래 5번 예산 칸이 열림).
   - 남은 예산 비율 막대 1개(오늘 화면 가계부 요약 막대와 같은 모양)
   - 그 아래 작은 숫자 3칸 가로 배치: "수입 1,200,000원" · "지출 380,000원" · "순흐름 +820,000원"

4. 거래 기록 카드 (이 화면의 핵심, 열려 있는 상태로)
   4-1. 기록 추가 칸
   - 지출 / 수입 전환 버튼 2개 (오늘 화면 가계부 카드의 지출·수입 토글과 같은 모양)
   - 금액 입력 (숫자 키패드, "금액 (원)")
   - 분류: 칩 버튼으로 하나 선택
     - 지출일 때: 식비 · 교통 · 쇼핑 · 생활 · 교육 · 세금 · 기타
     - 수입일 때: 급여 · 용돈 · 기타
   - 내용 입력 (선택, 예: "점심". 비우면 분류 이름으로 저장된다는 안내를 placeholder로)
   - 날짜 입력 (기본값 오늘)
   - 저장 버튼 (전체 폭, 숲녹색, "지출 저장하기" / "수입 저장하기")

   4-2. 기록 검색 (작은 줄, 기본은 접힘)
   - 이름 검색 입력, 날짜 선택, 종류 선택(모든 종류 / 수입 / 지출 / 이전 시작 잔액), 분류 선택(모든 분류 + 위 분류들 + 이전 시작 잔액), "초기화" 버튼
   - 검색 중일 때 접힌 제목이 "기록 검색 · 적용 중"으로 바뀝니다.

   4-3. 거래 목록
   - 목록 위에 개수 문구: "선택한 달 12개" 또는 검색 중이면 "검색 결과 3개"
   - 날짜별로 묶어서 표시: 묶음 머리 "11월 20일 금요일"
   - 거래 한 줄에 들어가는 것:
     - 내용 (예: "점심")
     - 작은 글씨 분류 (예: "식비"). 정기 거래로 자동 기록된 것은 "정기 · 식비", 예전 버전에서 넘어온 기록은 "이전 시작 잔액"
     - 금액: 수입은 "+50,000원" 숲녹색, 지출은 "-12,000원" 기본 글자색, 이전 시작 잔액은 부호 없이 회색
     - "수정" 버튼, "삭제" 버튼(코랄 글자). 캘린더 일정 줄의 수정·삭제 버튼과 같은 모양
   - **수정은 팝업이 아니라 그 줄이 그 자리에서 편집 칸으로 펼쳐지는 방식**: 내용, 금액, 날짜, 분류 입력 + "취소" / "저장" 버튼. 예시로 목록 중 한 줄을 이 편집 상태로 그려 주세요.
   - 기록이 없을 때 빈 상태 문구: "선택한 달의 가계부 기록이 없습니다." / 검색 결과가 없을 때: "조건에 맞는 가계부 기록이 없습니다."

5. 월별 예산 (접히는 칸, 기본 닫힘, 캘린더의 "일정 추가" 접힘과 같은 모양)
   - 접힌 제목: "월별 예산 · 3개 분류 설정" (없으면 "월별 예산 · 미설정")
   - 펼치면:
     - 안내 한 줄 (예: "2026-11 저장된 예산입니다." / "아직 이 달의 예산이 없습니다." / "2026-10 예산을 이어받을 예정입니다.")
     - 분류별 사용 현황 줄: 분류 이름, "800,000원 중 380,000원 사용", 오른쪽에 "420,000원 남음" 또는 코랄 "35,000원 초과", "48% 사용", 얇은 막대
     - 예산을 정하지 않은 분류에서 쓴 돈: "예산 미설정 분류 지출 52,000원"
     - 안쪽 접힘 "예산 설정·수정": 지출 분류 선택 → "현재 예산 300,000원 · 사용 120,000원 · 180,000원 남음" → 월 예산 금액 입력 → 작은 안내 "빈칸으로 저장하면 이 분류의 예산을 해제합니다. 0은 0원 예산입니다." → "이 분류 예산 저장" 버튼, "다시 불러오기" 글자 버튼

6. 정기 수입·지출 (접히는 칸, 기본 닫힘)
   - 접힌 제목: "정기 수입·지출 2개"
   - 펼치면:
     - 안내: "계좌에서 출금하지 않고 가계부에 자동으로 기록합니다. 매월 말일보다 큰 기록일은 말일에 기록합니다."
     - 정기 거래 줄: 이름(예: "월세"), "지출 · 생활 · 500,000원 · 매월 25일", 상태 "사용 중 · 다음 2026-11-25" (또는 "일시정지", "종료")
     - 줄마다 버튼: "수정", "일시정지"(일시정지 상태면 "다시 시작"), "종료" → 한 번 누르면 "종료 확인"으로 바뀌는 2단계
     - "추가" 버튼, "다시 불러오기" 글자 버튼
     - 추가/수정 입력 칸(펼친 예시 1개): 종류(지출/수입), 분류, 이름, 금액(원), 매월 기록일(1~31), 시작일, 종료일(비워두면 계속), 기준 시간대(예: Asia/Seoul), "예정일 확인" 버튼 → "다음 기록 예정일: 2026-11-25" 문구 → "저장" 버튼(예정일 확인 전에는 비활성), "취소"

7. 수입·지출 분석 (접히는 칸, 기본 닫힘)
   - 펼치면: "지출" / "수입" 전환 버튼, 도넛 차트(가운데 "총지출 380,000원"), 분류별 줄(색 점, 분류 이름, 금액, 비율 %, 얇은 막대), 금액이 큰 순서
   - 내역이 없으면 "선택한 달의 지출 내역이 없습니다."

[하지 말 것]
- 위 목록에 없는 기능을 넣지 마세요: 계좌·카드 연동, 자산/잔액 총계, 저축 목표, 영수증 촬영, AI 분석·조언, 월 비교 그래프, 내보내기, 공유, 플로팅 + 버튼, 별도 팝업 창 등 모두 금지.
- 하단 탭바, 상태바, 휴대폰 틀을 그리지 마세요.
- 다크 모드는 만들지 마세요.
- "데이터 초기화", "데모" 같은 시연용 버튼을 넣지 마세요.
- 분류 이름과 버튼 문구를 바꾸지 마세요(위에 적힌 한국어 그대로).
- 다른 화면(오늘·캘린더·더보기)의 디자인은 바꾸지 마세요.

[출력 형식: 반드시 이 방식으로]
- 결과물은 **정적 HTML 파일 한 개(code.html) + 화면 이미지(screen.png)** 로 주세요.
- code.html 규칙:
  - Tailwind CSS(CDN) + 같은 파일 안의 tailwind.config로 위 색을 토큰으로 정의
  - **JavaScript로 화면을 그리지 마세요.** 모든 카드와 줄을 HTML 마크업으로 직접 적어 주세요. 데이터 배열 + 렌더 함수 방식, React, JSON 명세 방식은 쓰지 않습니다.
  - 접히는 칸은 `<details>` / `<summary>` 로 만들어 주세요(스크립트 없이 열리고 닫히게).
  - `style="..."` 속성을 쓰지 말고 색·크기는 Tailwind 클래스로만 지정하세요. 막대 길이와 도넛 비율도 예시 값 클래스(예: `w-[48%]`)로 적어 주세요.
  - 예시 데이터는 현실적인 한국어 값으로(금액은 "12,000원" 형식). 그리고 한 화면 안에 다음 상태를 모두 보이게: 편집 중인 거래 1줄, 예산 초과 분류 1개, 일시정지된 정기 거래 1개.
  - screen.png에서는 5·6·7번 접히는 칸을 모두 펼친 상태로 보여 주세요. code.html에서는 닫힌 상태가 기본입니다.
- 위 형식이 왜 필요한지: 이 HTML을 앱에 글자 그대로 옮기고, 버튼 동작과 실제 데이터만 연결합니다. 그래서 HTML 구조가 곧 최종 화면이 됩니다.
