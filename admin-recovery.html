인증 앱을 사용할 수 없나요?

복구는 Supabase 프로젝트 소유자임을 확인한 뒤 진행합니다. 이 페이지에서 인증을 해제하거나 운영자 권한을 새로 부여하지 않습니다.

먼저 확인해 주세요

  • 기존 인증 앱을 복원하거나 본인이 설정해 둔 동기화·백업으로 인증번호를 확인할 수 있는지 살펴보세요.
  • 번호가 틀리면 휴대폰 날짜·시간을 자동으로 맞추고 새 번호로 다시 시도하세요.
  • 비밀번호를 잊었다면 일반 앱의 비밀번호 찾기를 사용하세요. 비밀번호 변경만으로 2단계 인증이 해제되지는 않습니다.

분실한 인증 수단 복구 순서

  1. Supabase 사용자 관리에 프로젝트 소유자 계정으로 직접 로그인하세요. Supabase 자체의 2단계 인증도 완료해야 합니다.
  2. 운영자 가입 이메일로 사용자를 찾고, 대상 이메일·사용자 ID가 본인 계정과 일치하는지 확인하세요.
  3. 해당 사용자의 MFA 인증 수단에서 분실한 인증 수단만 해제하세요. 사용자 계정 자체를 삭제하면 안 됩니다. 해제 전 계정과 인증 수단을 다시 확인하세요.
  4. 운영실에서 로그아웃한 뒤 다시 로그인하세요. 새 인증 앱으로 QR을 등록하고 6자리 인증을 마쳐야 운영 기능을 사용할 수 있습니다.
  5. 복구 후 운영 기록에서 모르는 조치가 있는지 확인하고, 탈취가 의심되면 비밀번호도 변경하세요.

Supabase 소유자 계정에도 접근할 수 없거나 MFA 관리 기능을 찾지 못하면 Supabase 공식 지원을 통해 프로젝트 소유권을 확인하세요. DB의 인증 테이블을 직접 삭제하는 방식은 사용하지 마세요.

다음 분실에 대비하기

인증 앱의 백업·복원 방법을 미리 확인하고, Supabase 계정의 복구 수단도 안전하게 보관하세요. QR 코드, 인증번호, 관리자 비밀키를 제보·채팅·공개 저장소에 올리지 마세요.

이 안내는 복구 절차입니다. 실제 인증 수단 해제는 자동 실행되지 않습니다.
