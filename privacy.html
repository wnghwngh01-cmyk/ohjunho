개인정보처리방침

베타 운영용 초안 · 최종 출시 전 개발자 연락처와 실제 운영 정책을 법률 검토와 함께 확정해야 합니다.

나의 연구실(이하 “서비스”)은 사용자가 자신의 기록과 포트폴리오를 관리할 수 있도록 계정 및 콘텐츠 데이터를 처리합니다. 개인 연구실 원본은 기본 비공개이며, 사용자가 직접 광장 공유를 선택한 사본만 다른 사용자에게 공개됩니다.

1. 처리하는 정보

  • 계정: 이메일, 인증에 필요한 정보
  • 프로필: 표시 이름, 연구실 이름, 공개 주소 ID, 소개
  • 사용자가 작성한 데이터: 기록, 일정, 습관 체크, 목표, 프로젝트, 아이디어, 작업물, 가계부
  • 사용자가 업로드한 사진 및 문서
  • 커뮤니티 이용 시: 공개 게시물, 팔로우, 좋아요, 댓글/피드백, 개선 제안
  • 커뮤니티 안전 기능 이용 시: 차단 목록, 콘텐츠/사용자 신고 사유 및 설명
  • 비공개 보안 제보 내용
  • 약관 동의 버전 및 동의 시각

2. 이용 목적

계정 인증, 기기 간 동기화, 개인 포트폴리오 관리, 사용자가 선택한 공개 콘텐츠의 제공, 커뮤니티 상호작용, 서비스 개선 및 보안 대응에 사용합니다.

3. 공개 범위

기록·일정·가계부·아이디어 등 개인 원본 데이터는 기본 비공개입니다. 광장에는 사용자가 공유 버튼을 통해 별도로 만든 공개용 사본만 노출됩니다. 팔로워 공개를 선택한 게시물은 해당 사용자를 팔로우한 로그인 사용자에게만 표시하도록 접근 정책을 적용합니다.

4. 보관 및 삭제

계정이 유지되는 동안 데이터를 보관합니다. 사용자는 앱 설정 또는 외부 계정 삭제 페이지에서 계정 삭제를 요청할 수 있으며, 계정과 연결된 서비스 데이터 및 업로드 파일을 함께 삭제하도록 처리합니다. 법령상 보존 의무가 생기는 경우 그 항목과 기간은 이 방침에 별도로 고지합니다.

5. 처리 기반 서비스

서비스는 인증, 데이터베이스 및 파일 저장을 위해 Supabase를 사용합니다. 실제 출시 전 사용 중인 인프라 지역, 하위처리자 및 국외 이전 여부를 확인하여 필요한 고지를 추가해야 합니다.

6. 보안과 커뮤니티 안전

사용자별 Row Level Security(RLS), 개인/공개 Storage 분리, HTTPS, 계정 기반 접근제어를 적용합니다. 공개 커뮤니티에서는 신고와 사용자 차단 기능을 제공하고, 신고 내용은 공개 게시판에 노출하지 않습니다. 서비스 보안 문제는 공개 게시판 대신 비공개 보안 제보 기능을 이용해 주세요.

7. 이용자의 권리

사용자는 자신의 데이터를 조회·수정·삭제하고 JSON 형식으로 내보낼 수 있습니다. 공개한 항목은 언제든 광장에서 내릴 수 있습니다.
